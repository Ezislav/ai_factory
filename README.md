# ai-factory

Делает ролик для YouTube по теме из `config.yaml`. Этапы идут по порядку:

| № | Папка | Что делает | Результат |
|---|---|---|---|
| 1 | `01_scenario` | сценарий | `script.md` |
| 2 | `02_storyboard` | раскадровка | `storyboard.md` |
| 3 | `03_visual` | картинки и их проверка | `1.png`, `2.png`, ... и `review.html` |
| 4 | `04_audio` | озвучка | `voice.wav` |
| 5 | `05_montage` | монтаж | проект FilmCraft `video.fcproj` или готовый `video.mp4` |

Всё складывается в `projects/<имя ролика>/`, в папки с теми же именами.

## Подготовка

1. Установите Python, [ffmpeg](https://ffmpeg.org/download.html) и FilmCraft. Библиотеки программа поставит сама при первом запуске.
2. Скопируйте `.env.example` в `.env` и впишите ключи. Ключи пишите только в `.env`: он не попадает на GitHub.
3. В `config.yaml` впишите тему (`topic`) и, для озвучки, `template_id` шаблона из кабинета Lumean.

## Команды

Вместо `my_video` подставьте имя ролика. Новый ролик — новое имя.

Продолжить с первого незаконченного этапа, готовое не трогать:

```bash
python run.py --project my_video --continue
```

То же самое, без ключа:

```bash
python run.py --project my_video
```

Только выбранные этапы:

```bash
python run.py --project my_video --only 4
```

```bash
python run.py --project my_video --only 4,5
```

С выбранного этапа и до конца:

```bash
python run.py --project my_video --2
```

С отдельного шага этапа и до конца (здесь шаг 3 этапа 1):

```bash
python run.py --project my_video --1.3
```

С нуля и до конца:

```bash
python run.py --project my_video --anew
```

По этапам, с проверкой после каждого:

```bash
python run.py --project my_video --step
```

Можно выбрать только один из ключей `--continue`, `--only`, `--anew` и номер этапа. `--step` добавляется к любому из них, например `--anew --step`.

### Дополнительные ключи

| Ключ | Что делает |
|---|---|
| `--topic "Тема"` | тема вместо `topic` из `config.yaml` |
| `--set notes="Пожелание"` | параметр этого ролика, запоминается; можно указать несколько раз |
| `--provider mock` | проверка без интернета и денег: тексты-заглушки, однотонные картинки, тон вместо голоса |
| `--provider openai` | одна нейросеть из `config.yaml` на весь запуск |
| `-v` | подробный журнал |

Показать шаги, нейросети и генераторы:

```bash
python run.py --list
```

Остановить работу: `Ctrl+C`. Готовые файлы сохранятся, следующий запуск продолжит с места остановки.

## Что происходит со старыми файлами

| Команда | Этапы, которые не затронуты | Текст: этапы 1 и 2 | Файлы: этапы 3 и 4 | Монтаж: этап 5 |
|---|---|---|---|---|
| `--continue` или без ключа | не трогаются | готовое пропускается | делается только недостающее | только если что-то изменилось |
| `--only 4,5` | не запускаются, даже если не готовы | пишется заново | переделывается только изменившееся | только если что-то изменилось |
| `--2` | не запускаются | пишется заново | переделывается только изменившееся | только если что-то изменилось |
| `--anew` | таких нет | всё делается заново | всё делается заново, это снова стоит денег | собирается заново |

Что считается изменившимся:

- **Картинка** переделывается, если поменялось описание её сцены или стиль ролика.
- **Озвучка кадра** переделывается, если поменялся его текст или настройки голоса в `config.yaml`.
- **Новый этап 2 или 1** обычно меняет почти все кадры, поэтому картинки и озвучка после него делаются заново и за них снова придётся заплатить.

Ничего не удаляется:

- Прежние варианты файлов уходят в папку `old` рядом с ними, например `03_visual/old/5_v1.png`.
- При `--anew` все прежние результаты уходят в `projects/my_video/old/<дата_время>/`. Тема и параметры ролика остаются на месте.

Если после `--only 1` запустить `--continue`, раскадровка сама не обновится: она уже готова. Чтобы новый сценарий дошёл до конца, запускайте `--1`.

### Пробный запуск картинок

Пока в `config.yaml` стоит `limit: 3` (раздел `03_visual`), картинки делаются только для первых трёх кадров:

- `--continue` и `--3` останавливаются на этапе 3 и подсказывают, что делать дальше.
- `--only 4,5` собирает короткий ролик из этих трёх кадров.
- `--step` проходит все этапы на этих трёх кадрах.
- `limit: 0` делает картинки для всех кадров.

## Монтаж в FilmCraft

Этап 5 собирает проект `projects/my_video/05_montage/video.fcproj`. Откройте его в FilmCraft через **File → Open Project** и монтируйте как обычно. Готовый ролик выводите из самой программы, через вкладку **Export**.

В проекте уже всё разложено:

- **Дорожка V1:** картинки и видео кадров, файл `5.png` — это кадр 5.
- **Дорожка A1:** озвучка, по клипу на кадр.
- **Камера:** наезды и панорамы сделаны ключевыми кадрами в **Effect Controls**.
- **Переходы:** обычные Cross Dissolve и Dip to Black на стыках.

Что будет с вашими правками в проекте:

- **Пока материалы те же**, программа проект не трогает при любой команде, кроме `--anew`.
- **Если изменились** картинки, озвучка, камера или переходы в раскадровке, проект соберётся заново. Прежний вместе с вашими правками уйдёт в `05_montage/old/video_v1.fcproj`, в журнале появится предупреждение. Новый проект ваших правок не содержит.
- **Правки в `05_montage/redo.txt`** тоже собирают проект заново. Поэтому, начав монтировать вручную, меняйте камеру и переходы уже в FilmCraft.

Перед новым запуском закройте проект в FilmCraft: иначе в окне останется прежняя версия.

Проект ссылается на файлы ролика по полному пути. Если переименовать или перенести папку ролика, в том числе после `--anew`, программа покажет файлы как отсутствующие и их нужно будет указать заново.

Чтобы получать готовый `video.mp4` без FilmCraft, в `config.yaml` в разделе `05_montage` поставьте `ffmpeg: true` и `filmcraft: false`.

## Проверка по этапам

```bash
python run.py --project my_video --step
```

После каждого этапа программа останавливается и показывает, какой файл проверить и где лежит `redo.txt`:

1. Посмотрите результат.
2. Если нужны правки, впишите их в `redo.txt` этого этапа и сохраните файл.
3. Нажмите **Enter**. Если правки есть, этап их применит и снова остановится. Если правок нет, программа перейдёт к следующему этапу.
4. Чтобы прерваться, введите `q` и нажмите Enter. Та же команда потом продолжит с этого места.

Проверенные этапы запоминаются и больше не останавливают работу, пока их результат не изменится.

## Правки: redo.txt

У каждого этапа свой файл `redo.txt` в папке этапа ролика. Строки с `#` в начале не считаются. Правки применяются при следующем запуске, и `--step` для этого не обязателен. После применения файл очищается.

| Этап | Что писать | Что произойдёт |
|---|---|---|
| 1, сценарий | `Сделай вступление короче` | нейросеть внесёт правку в `script.md` |
| 2, раскадровка | `5: покажи закат над морем` или `Сделай стиль темнее` | изменятся только затронутые кадры; при смене стиля переделаются все картинки |
| 3, картинки | `5` или `5: сделай закат ярче` | картинка 5 сделается заново |
| 4, озвучка | `5` или `5: Новый текст кадра.` | кадр озвучится заново; новый текст запишется и в раскадровку |
| 5, монтаж | `5: вместо наезда отъезд` или `12: переход наплывом` | поменяются камера и переход; проект FilmCraft соберётся заново, прежний уйдёт в `old` |

Правка этапа 1 меняет сценарий, поэтому раскадровка строится заново, а за ней обычно и картинки с озвучкой. Текст диктора в отдельном кадре дешевле поправить на этапе 4.

На этапе 2 нельзя поменять текст диктора и границы кадров. Для этого есть этап 1.

Настройки всего ролика, например качество, размер и силу наезда, меняйте в `config.yaml`.

## Настройки

- `config.yaml` — тема, этапы, параметры, нейросети и генераторы. Пояснения есть прямо в файле.
- `.env` — ключи. Образец без ключей лежит в `.env.example`.
