Сделай раскадровку ролика «{{ title }}» (тема: «{{ topic }}»).

Текст диктора разбит на пронумерованные фразы. В скобках — сколько секунд звучит фраза.

{{ phrases }}

Сгруппируй фразы в кадры:
- кадр — одна или несколько фраз подряд: first — номер первой фразы, last — последней;
- кадры идут по порядку и покрывают все фразы ровно по одному разу, без пропусков и повторов;
- кадр не выходит за границу блока «## …»;
- обычная длительность кадра — {{ shot_seconds_min }}–{{ shot_seconds_max }} секунд; новая мысль — новый кадр;
- длинная фраза может быть отдельным кадром, даже если она длиннее.

Для каждого кадра:
- visual — что на экране: сюжет, объекты, фон, освещение, ракурс. Одно-два конкретных предложения по-русски.
  Без надписей, букв и логотипов на самой картинке. Реальных известных людей не изображай фотореалистично —
  только стилизованно или через предметы и места;
{% if images_per_shot > 1 %}
- image_prompts — {{ images_per_shot }} промпта для генератора картинок, на английском. Картинки сменяют друг
  друга внутри кадра через равные промежутки времени, поэтому это разные моменты, ракурсы или детали одной сцены
  по ходу текста диктора, а не варианты одной картинки. Первая — главная: в коротком кадре программа оставит
  только первые. Для video-кадра — ровно один промпт. Каждый промпт подробный и конкретный (объекты,
  их расположение, фон, свет, цвет, ракурс), 30–70 слов, без стиля — стиль добавится отдельно;
{% else %}
- image_prompts — список из одного промпта: то же, что visual, для генератора картинок, на английском,
  подробно и конкретно (объекты, их расположение, фон, свет, цвет, ракурс), 30–70 слов, без стиля — стиль
  добавится отдельно;
{% endif %}
{% if video_shots %}
- media — image (картинка, которую оживляет движение камеры) или video (короткое видео, которое начинается
  с этой картинки). Видео дорогое: не больше {{ video_shots }} кадров на весь ролик, и только там, где движение
  важнее всего — хук, процесс, который надо показать в динамике. Видео-кадр не длиннее {{ video_seconds_max }} секунд;
- motion — для video: что именно движется в кадре, на английском, одно-два предложения; для image — пустая строка;
{% else %}
- media — всегда image; motion — всегда пустая строка;
{% endif %}
- shot_type — план: wide (общий), medium (средний), close (крупный), macro (макро), aerial (с высоты);
- camera — движение камеры по картинке: static, zoom_in (наезд), zoom_out (отъезд),
  pan_left, pan_right, pan_up, pan_down (панорамы). Чередуй, не ставь одно и то же много раз подряд;
- transition — переход к кадру от предыдущего: cut (склейка, обычно), crossfade (наплыв — смена настроения
  или времени), fade_black (через чёрное — только между крупными блоками);
- on_screen_text — короткий титр поверх картинки (число, термин, имя), если он помогает понять; иначе пустая строка.

Выбери единый визуальный стиль всего ролика — style: на английском, одно-два предложения
для генератора картинок (тип изображения — фото, 3D, иллюстрация; свет; палитра; настроение). Стиль должен
подходить теме и аудитории: научно-популярной теме — понятная наглядная картинка, истории — атмосферная.
Все кадры описывай в этом стиле, чтобы ролик выглядел цельным: одни и те же места и предметы описывай одинаково.
